# 分页存储管理系统说明文档

## 系统概述

本系统实现了一个完整的分页存储管理系统，模拟了操作系统中的分页内存管理机制。系统支持逻辑地址到物理地址的转换、页表管理、内存分配和越界检查等功能。

## 分页存储原理

### 目的
分页存储管理的主要目的是解决内存碎片问题和实现虚拟内存管理：
1. **消除外部碎片** - 通过固定大小的页面划分，避免内存分配时的外部碎片问题
2. **支持虚拟内存** - 允许进程的地址空间大于物理内存，通过页面置换实现内存扩展
3. **内存保护** - 通过页表实现不同进程间的内存隔离和保护
4. **提高内存利用率** - 按需分配页面，减少内存浪费

### 原理
分页存储管理的基本原理是将进程的逻辑地址空间和物理内存空间都划分为固定大小的页面/块：

1. **地址空间划分**：
   - 逻辑地址空间被划分为大小相等的页面（Page）
   - 物理内存空间被划分为大小相等的块（Frame/Block）
   - 页面大小通常为2的幂次方（如4KB）

2. **地址转换机制**：
   - 逻辑地址 = 页号 + 页内偏移
   - 物理地址 = 块号 + 页内偏移
   - 通过页表完成页号到块号的映射

3. **页表作用**：
   - 存储每个页面对应的物理块号
   - 包含访问控制信息（有效位、修改位、引用位等）
   - 实现逻辑地址到物理地址的转换

4. **内存管理流程**：
   - 进程创建时分配所需页面
   - 运行时通过页表进行地址转换
   - 缺页时触发页面置换
   - 进程结束时回收所有页面

### 关键数据结构
分页存储管理系统的核心数据结构包括：

1. **页表项结构体（PageTableEntry）**：
   - 存储页号到块号的映射关系
   - 包含访问控制位：有效位、修改位、引用位

   **实际代码实现**：
   ```cpp
   // 页表项结构体
   struct PageTableEntry {
       int pageNumber;     // 页号
       int blockNumber;    // 块号
       bool valid;         // 有效位
       bool modified;      // 修改位
       bool referenced;    // 引用位

       PageTableEntry() : pageNumber(-1), blockNumber(-1),
                         valid(false), modified(false), referenced(false) {}
   };
   ```

2. **内存块结构体（MemoryBlock）**：
   - 记录物理内存块的使用状态
   - 包含块号、分配状态、占用进程ID、占用页号

   **实际代码实现**：
   ```cpp
   // 内存块结构体
   struct MemoryBlock {
       int blockNumber;    // 块号
       bool allocated;     // 是否已分配
       int processId;      // 占用进程ID
       int pageNumber;     // 占用页号

       MemoryBlock() : blockNumber(-1), allocated(false),
                      processId(-1), pageNumber(-1) {}
   };
   ```

3. **分页存储管理类（PagingMemoryManager）**：
   - 封装整个分页存储管理系统的功能
   - 包含系统参数和核心算法
   - 包含页表存储和内存块存储

   **实际代码实现**：
   ```cpp
   class PagingMemoryManager {
   private:
       int pageSize;               // 页面大小（字节）
       int totalMemorySize;        // 总内存大小（字节）
       int totalBlocks;            // 总块数
       int totalPages;             // 总页数
       int processMemorySize;      // 进程内存需求大小（字节）

       vector<PageTableEntry> pageTable;   // 页表存储
       vector<MemoryBlock> memoryBlocks;   // 内存块存储

   public:
       // 构造函数
       PagingMemoryManager(int pageSize, int totalMemory, int processMemory) {
           this->pageSize = pageSize;
           this->totalMemorySize = totalMemory;
           this->processMemorySize = processMemory;

           // 计算总块数和总页数
           totalBlocks = totalMemorySize / pageSize;
           totalPages = processMemorySize / pageSize;

           // 如果进程内存需求不能整除页面大小，需要额外一页
           if (processMemorySize % pageSize != 0) {
               totalPages++;
           }

           // 初始化页表
           pageTable.resize(totalPages);
           for (int i = 0; i < totalPages; i++) {
               pageTable[i].pageNumber = i;
           }

           // 初始化内存块
           memoryBlocks.resize(totalBlocks);
           for (int i = 0; i < totalBlocks; i++) {
               memoryBlocks[i].blockNumber = i;
           }

           cout << "分页存储管理系统初始化完成！" << endl;
           cout << "页面大小: " << pageSize << " 字节" << endl;
           cout << "总内存大小: " << totalMemorySize << " 字节" << endl;
           cout << "进程内存需求: " << processMemorySize << " 字节" << endl;
           cout << "总块数: " << totalBlocks << endl;
           cout << "总页数: " << totalPages << endl;
       }

       // 核心方法声明
       bool allocateMemory(int processId);
       bool logicalToPhysical(int logicalAddress, int& physicalAddress);
       void displayPageTable();
       void displayMemoryStatus();
       void modifyPage(int pageNumber, bool modified);
       void displaySystemInfo();
   };
   ```

## 系统功能

### 1. 系统信息显示
- 显示系统初始化参数
- 计算并显示地址位数信息
- 逻辑地址位数、页内偏移位数、页号位数

### 2. 内存分配
- 为进程分配所需的内存页面
- 自动检查内存是否足够
- 建立页表映射关系
- 更新内存块状态

### 3. 逻辑地址转换
- 输入逻辑地址（十进制整数，范围：0 ~ 进程内存需求-1）
- 计算页号和页内偏移
- 检查页号是否越界
- 检查页表项是否有效
- 计算物理地址
- 更新页表引用位

**逻辑地址格式说明**：
- **输入格式**：十进制整数
- **有效范围**：0 ~ 16383（基于16KB进程内存需求）
- **示例**：
  - 有效地址：0, 100, 4095, 8192, 16383
  - 无效地址：-1, 20000（越界）
- **计算方式**：
  - 页号 = 逻辑地址 / 页面大小（4096）
  - 页内偏移 = 逻辑地址 % 页面大小（4096）

### 4. 页表管理
- 显示完整的页表内容
- 包括页号、块号、有效位、修改位、引用位
- 支持修改页表项的修改位

### 5. 内存状态显示
- 显示所有内存块的状态
- 显示块号、分配状态、占用进程ID、占用页号

## 核心算法

### 逻辑地址到物理地址转换算法
1. **计算页号和偏移**: `pageNumber = logicalAddress / pageSize`
2. **越界检查**: 检查页号是否在有效范围内
3. **有效性检查**: 检查页表项是否有效
4. **获取块号**: 从页表获取对应的块号
5. **计算物理地址**: `physicalAddress = blockNumber * pageSize + offset`

### 内存分配算法
1. **需求计算**: 根据进程内存需求计算所需页面数
2. **可用性检查**: 检查是否有足够的空闲内存块
3. **分配内存**: 按顺序分配空闲内存块
4. **更新页表**: 建立页号到块号的映射关系

## 错误处理

### 越界错误
- 当页号超出有效范围时提示错误
- 显示有效的页号范围

### 内存不足错误
- 当可用内存块不足时提示错误
- 显示需要的块数和可用块数

### 无效页表项错误
- 当访问的页不在内存中时提示错误
