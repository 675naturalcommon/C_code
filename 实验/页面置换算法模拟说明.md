# 页面置换算法模拟系统说明文档

## 实验目的
1. **理解页面置换的基本原理**：掌握虚拟内存管理中页面置换的核心概念和工作机制
2. **掌握常见页面置换算法的实现方法**：深入理解FIFO、OPT、LRU、LFU、Clock和改进Clock算法的实现细节
3. **分析不同算法的性能差异**：通过实验数据对比各算法在缺页率、置换次数等方面的表现

## 实验内容
本实验通过模拟页面置换过程，实现并比较六种主要的页面置换算法：
1. **FIFO（先进先出）算法**：基于队列结构，置换最早进入内存的页面
2. **OPT（最优置换）算法**：理论最优算法，置换将来最长时间不会被使用的页面
3. **LRU（最近最少使用）算法**：基于局部性原理，置换最近最长时间未被使用的页面
4. **LFU（最不经常使用）算法**：基于访问频率，置换访问频率最低的页面
5. **Clock（时钟）算法**：基于循环链表和访问位，置换访问位为0的页面
6. **改进Clock算法**：基于循环链表、访问位和修改位，四轮扫描选择置换页面

实验系统提供手动输入和随机生成两种访问序列输入方式，支持详细的执行过程展示和性能比较。

## 实验原理

### 页面置换的基本概念
在虚拟内存管理系统中，当进程需要访问的页面不在物理内存中时，会发生缺页中断。此时操作系统需要从磁盘中调入该页面到物理内存。如果物理内存已满，则必须选择一个页面进行置换，以腾出空间给新页面。页面置换算法的目标是最小化缺页率，提高系统性能。

### 页面置换算法的评价指标
1. **缺页次数**：访问序列中发生缺页的总次数
2. **置换次数**：需要置换页面的次数（不包括首次加载）
3. **缺页率** = (缺页次数 / 总访问次数) × 100%
4. **算法复杂度**：算法的时间复杂度和空间复杂度
5. **实现难度**：算法的实现复杂度和硬件支持需求

### 实验设计原理
本实验通过模拟页面置换过程，对比分析不同算法的性能差异。实验系统设计包括：
1. **输入模块**：支持用户输入物理块数和访问序列，或随机生成访问序列
2. **处理模块**：实现六种页面置换算法，记录每一步的执行过程
3. **输出模块**：显示算法执行过程、物理块状态和性能比较结果

通过对比不同算法在相同访问序列下的表现，可以直观理解各算法的优缺点和适用场景。

## 算法原理

### 页面置换算法概述
在虚拟内存系统中，当物理内存已满且需要加载新页面时，必须选择一个页面进行置换。不同的置换策略会影响系统性能。

### 1. FIFO（先进先出）算法
**原理**：选择最早进入内存的页面进行置换。

**特点**：
- 实现简单，只需要一个队列记录页面进入顺序
- 可能存在Belady异常：增加物理块数可能导致缺页率增加
- 不考虑页面的使用频率和最近使用情况

**执行流程**：
1. 维护一个队列记录页面进入顺序
2. 当发生缺页且物理块已满时，置换队列前端的页面
3. 新页面加入队列尾部

### 2. OPT（最优置换）算法
**原理**：选择将来最长时间不会被使用的页面进行置换。

**特点**：
- 理论上最优的页面置换算法
- 需要预知未来的页面访问序列，实际中无法实现
- 主要用于性能比较的基准

**执行流程**：
1. 对于每个物理块中的页面，查找其下一次被访问的位置
2. 选择将来最长时间不会被访问的页面进行置换
3. 如果页面不会再被访问，优先置换

### 3. LRU（最近最少使用）算法
**原理**：选择最近最长时间未被使用的页面进行置换。

**特点**：
- 基于局部性原理，性能接近OPT算法
- 需要记录每个页面的最近访问时间
- 实际系统中常用，但实现开销较大

**执行流程**：
1. 为每个物理块中的页面记录最近访问时间
2. 当发生缺页且物理块已满时，选择最近访问时间最早的页面
3. 每次访问页面时更新其最近访问时间

### 4. LFU（最不经常使用）算法
**原理**：选择访问频率最低的页面进行置换。

**特点**：
- 考虑页面的历史访问频率
- 可能保留不再使用的"冷"页面
- 需要维护访问频率计数器

**执行流程**：
1. 为每个物理块中的页面记录访问频率
2. 当发生缺页且物理块已满时，选择访问频率最低的页面
3. 访问频率相同时，选择最近访问时间最早的页面（打破平局）
4. 每次访问页面时增加其访问频率

### 5. Clock（时钟）算法
**原理**：基于循环链表和访问位，选择访问位为0的页面进行置换。

**特点**：
- 实现相对简单，性能较好
- 使用访问位（0/1）记录页面最近是否被访问
- 时钟指针循环扫描，模拟循环链表

**执行流程**：
1. 为每个物理块中的页面设置访问位，初始为0
2. 页面被访问时，访问位置为1
3. 当发生缺页且物理块已满时：
   - 时钟指针循环扫描物理块
   - 如果当前页面的访问位为0，置换该页面
   - 如果访问位为1，将其置为0，继续扫描
4. 新页面加入时，访问位置为1

### 6. 改进Clock算法
**原理**：基于循环链表、访问位和修改位，四轮扫描选择置换页面。

**特点**：
- 考虑页面的访问位和修改位
- 优先置换既未被访问又未被修改的页面
- 性能优于简单Clock算法

**执行流程**：
1. 为每个物理块中的页面设置访问位和修改位
2. 页面分类：(0,0)未访问未修改、(0,1)未访问已修改、(1,0)已访问未修改、(1,1)已访问已修改
3. 当发生缺页且物理块已满时，四轮扫描：
   - 第1轮：寻找(0,0)类页面
   - 第2轮：寻找(0,1)类页面
   - 第3轮：将所有访问位置位为0
   - 第4轮：再次寻找(0,1)类页面
4. 新页面加入时，访问位置为1，修改位置为0

## 算法比较

| 算法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| FIFO | 实现简单，开销小 | 性能较差，存在Belady异常 | 对性能要求不高的简单系统 |
| OPT  | 理论最优，缺页率最低 | 无法实际实现，需要预知未来 | 性能比较基准 |
| LRU  | 性能接近OPT，基于局部性原理 | 实现开销大，需要硬件支持 | 高性能系统，有硬件支持的环境 |
| LFU  | 考虑历史访问模式 | 可能保留不再使用的页面，实现复杂 | 访问模式相对稳定的系统 |
| Clock | 实现相对简单，性能较好 | 需要维护访问位，可能多次扫描 | 中等性能要求的系统 |
| 改进Clock | 考虑访问位和修改位，性能优于简单Clock | 实现复杂，需要维护两个标志位 | 高性能系统，需要平衡性能和实现复杂度 |

**FIFO算法实现**
```c
void fifoAlgorithm(int frameCount, int seqLength, int sequence[], AlgorithmResult *result) {
    int frames[MAX_FRAMES];
    int front = 0;

    for (int i = 0; i < frameCount; i++) {
        frames[i] = -1;
    }

    result->pageFaults = 0;
    result->replacements = 0;

    printf("步骤\t访问页面\t物理块状态\t\t缺页\n");
    printf("------------------------------------------------\n");

    for (int i = 0; i < seqLength; i++) {
        int page = sequence[i];
        int found = 0;

        for (int j = 0; j < frameCount; j++) {
            if (frames[j] == page) {
                found = 1;
                break;
            }
        }

        if (!found) {
            result->pageFaults++;

            int emptySlot = -1;
            for (int j = 0; j < frameCount; j++) {
                if (frames[j] == -1) {
                    emptySlot = j;
                    break;
                }
            }

            if (emptySlot != -1) {
                frames[emptySlot] = page;
            } else {
                result->replacements++;
                frames[front] = page;
                front = (front + 1) % frameCount;
            }
        }

        printf("%2d\t%4d\t\t", i + 1, page);
        for (int j = 0; j < frameCount; j++) {
            if (frames[j] == -1)
                printf(" - ");
            else
                printf("%2d ", frames[j]);
        }
        printf("\t\t%s\n", found ? "否" : "是");
    }

    printf("FIFO算法完成: 缺页次数=%d, 置换次数=%d, 缺页率=%.2f%%\n",
           result->pageFaults, result->replacements, (float)result->pageFaults / seqLength * 100);
}
```

```c
void lruAlgorithm(int frameCount, int seqLength, int sequence[], AlgorithmResult *result) {
    int frames[MAX_FRAMES];
    int lastUsed[MAX_FRAMES];

    for (int i = 0; i < frameCount; i++) {
        frames[i] = -1;
        lastUsed[i] = -1;

        int page = sequence[i];

        int foundIndex = -1;

        for (int j = 0; j < frameCount; j++) {
            if (frames[j] == page) {
                found = 1;
                foundIndex = j;
                break;
            }
        }

        if (found) {
            lastUsed[foundIndex] = i;
            printf("%2d\t%4d\t\t", i + 1, page);
            for (int j = 0; j < frameCount; j++) {
                if (frames[j] == -1)
                    printf(" - ");
                else
                    printf("%2d ", frames[j]);
            }
            printf("\t\t否\t-\n");
        } else {
            result->pageFaults++;

            int emptySlot = -1;
            for (int j = 0; j < frameCount; j++) {
                if (frames[j] == -1) {
                    emptySlot = j;
                    break;
                }
            }

            if (emptySlot != -1) {
                frames[emptySlot] = page;
                lastUsed[emptySlot] = i;
                printf("%2d\t%4d\t\t", i + 1, page);
                for (int j = 0; j < frameCount; j++) {
                    if (frames[j] == -1)
                        printf(" - ");
                    else
                        printf("%2d ", frames[j]);
                }
                printf("\t\t是\t-\n");
            } else {
                result->replacements++;

                int lruIndex = 0;

                for (int j = 1; j < frameCount; j++) {
                    if (lastUsed[j] < minTime) {
                        minTime = lastUsed[j];
                        lruIndex = j;
                    }

                frames[lruIndex] = page;
                lastUsed[lruIndex] = i;

                printf("%2d\t%4d\t\t", i + 1, page);

                        printf(" - ");
                    else
                        printf("%2d ", frames[j]);
                }
                printf("\t\t是\t%d\n", replacedPage);
            }
        }
    }

    printf("LRU算法完成: 缺页次数=%d, 置换次数=%d, 缺页率=%.2f%%\n",
           result->pageFaults, result->replacements, (float)result->pageFaults / seqLength * 100);
```

```c
void lfuAlgorithm(int frameCount, int seqLength, int sequence[], AlgorithmResult *result) {
    int frames[MAX_FRAMES];
    int frequency[MAX_FRAMES];
    int lastUsed[MAX_FRAMES];

    for (int i = 0; i < frameCount; i++) {
        frames[i] = -1;
        frequency[i] = 0;
        lastUsed[i] = -1;
    }

    result->pageFaults = 0;
    result->replacements = 0;

    printf("步骤\t访问页面\t物理块状态(频率)\t\t缺页\t置换页面\n");
    printf("----------------------------------------------------------------\n");

    for (int i = 0; i < seqLength; i++) {
        int page = sequence[i];
        int found = 0;
        int foundIndex = -1;

        for (int j = 0; j < frameCount; j++) {
            if (frames[j] == page) {
                found = 1;
                foundIndex = j;
                frequency[j]++;
                lastUsed[j] = i;
                break;
            }
        }

        if (!found) {
            result->pageFaults++;

            int emptySlot = -1;
            for (int j = 0; j < frameCount; j++) {
                if (frames[j] == -1) {
                    emptySlot = j;
                    break;
                }
            }

            if (emptySlot != -1) {
                frames[emptySlot] = page;
                frequency[emptySlot] = 1;
                lastUsed[emptySlot] = i;
                printf("%2d\t%4d\t\t", i + 1, page);
                for (int j = 0; j < frameCount; j++) {
                    if (frames[j] == -1)
                        printf("   -  ");
                    else
                        printf("%2d(%d) ", frames[j], frequency[j]);
                }
                printf("\t\t是\t-\n");
            } else {
                result->replacements++;

                int lfuIndex = 0;
                int minFreq = frequency[0];
                int minTime = lastUsed[0];

                for (int j = 1; j < frameCount; j++) {
                    if (frequency[j] < minFreq || (frequency[j] == minFreq && lastUsed[j] < minTime)) {
                        minFreq = frequency[j];
                        minTime = lastUsed[j];
                        lfuIndex = j;
                    }
                }

                int replacedPage = frames[lfuIndex];
                frames[lfuIndex] = page;
                frequency[lfuIndex] = 1;
                lastUsed[lfuIndex] = i;

                printf("%2d\t%4d\t\t", i + 1, page);
                for (int j = 0; j < frameCount; j++) {
                    if (frames[j] == -1)
                        printf("   -  ");
                    else
                        printf("%2d(%d) ", frames[j], frequency[j]);
                }
                printf("\t\t是\t%d\n", replacedPage);
            }
        } else {
            printf("%2d\t%4d\t\t", i + 1, page);
            for (int j = 0; j < frameCount; j++) {
                if (frames[j] == -1)
                    printf("   -  ");
                else
                    printf("%2d(%d) ", frames[j], frequency[j]);
            }
            printf("\t\t否\t-\n");
        }
    }

    printf("LFU算法完成: 缺页次数=%d, 置换次数=%d, 缺页率=%.2f%%\n",
           result->pageFaults, result->replacements, (float)result->pageFaults / seqLength * 100);
}
```

**Clock算法实现**
```c
void clockAlgorithm(int frameCount, int seqLength, int sequence[], AlgorithmResult *result) {
    int frames[MAX_FRAMES];
    int referenceBits[MAX_FRAMES]; // 访问位 (0/1)
    int clockHand = 0; // 时钟指针

    for (int i = 0; i < frameCount; i++) {
        frames[i] = -1;
        referenceBits[i] = 0;
    }

    result->pageFaults = 0;
    result->replacements = 0;

    printf("步骤\t访问页面\t物理块状态(访问位)\t\t缺页\t置换页面\n");
    printf("----------------------------------------------------------------\n");

    for (int i = 0; i < seqLength; i++) {
        int page = sequence[i];
        int found = 0;
        int foundIndex = -1;

        // 检查页面是否已在物理块中
        for (int j = 0; j < frameCount; j++) {
            if (frames[j] == page) {
                found = 1;
                foundIndex = j;
                referenceBits[j] = 1; // 设置访问位为1
                break;
            }
        }

        if (!found) {
            result->pageFaults++;

            int emptySlot = -1;
            for (int j = 0; j < frameCount; j++) {
                if (frames[j] == -1) {
                    emptySlot = j;
                    break;
                }
            }

            if (emptySlot != -1) {
                frames[emptySlot] = page;
                referenceBits[emptySlot] = 1; // 新页面访问位设为1
                clockHand = (emptySlot + 1) % frameCount; // 指针移动到下一个位置

                for (int j = 0; j < frameCount; j++) {
                    if (frames[j] == -1)
                        printf("   -  ");

                        printf("%2d(%d) ", frames[j], referenceBits[j]);
                }
                printf("\t\t是\t-\n");
            } else {
                result->replacements++;

                // Clock算法：寻找访问位为0的页面
                int replaced = 0;
                int startHand = clockHand;
                int replacedPage = -1;
                int replacedIndex = -1;

                // 第一轮扫描：寻找访问位为0的页面
                while (!replaced) {
                    if (referenceBits[clockHand] == 0) {
                        replaced = 1;
                        replacedIndex = clockHand;
                        replacedPage = frames[clockHand];
                        frames[clockHand] = page;
                        referenceBits[clockHand] = 1; // 新页面访问位设为1
                    } else {
                        // 访问位置位为0，继续扫描
                        referenceBits[clockHand] = 0;
                    }
                    clockHand = (clockHand + 1) % frameCount;
                }

                printf("%2d\t%4d\t\t", i + 1, page);
                for (int j = 0; j < frameCount; j++) {
                    if (frames[j] == -1)
                        printf("   -  ");
                    else
                        printf("%2d(%d) ", frames[j], referenceBits[j]);
                }
                printf("\t\t是\t%d\n", replacedPage);
            }
        } else {
            printf("%2d\t%4d\t\t", i + 1, page);
            for (int j = 0; j < frameCount; j++) {
                if (frames[j] == -1)
                    printf("   -  ");
                else
                    printf("%2d(%d) ", frames[j], referenceBits[j]);
            }
            printf("\t\t否\t-\n");
        }
    }

    printf("Clock算法完成: 缺页次数=%d, 置换次数=%d, 缺页率=%.2f%%\n",
           result->pageFaults, result->replacements, (float)result->pageFaults / seqLength * 100);
}
```

```c
void improvedClockAlgorithm(int frameCount, int seqLength, int sequence[], AlgorithmResult *result) {
    int frames[MAX_FRAMES];
    int referenceBits[MAX_FRAMES]; // 访问位 (0/1)
    int modifyBits[MAX_FRAMES];    // 修改位 (0/1) - 模拟修改位
    int clockHand = 0; // 时钟指针

    // 初始化
    for (int i = 0; i < frameCount; i++) {
        frames[i] = -1;
        referenceBits[i] = 0;
        modifyBits[i] = 0; // 初始修改位为0
    }

    result->pageFaults = 0;
    result->replacements = 0;

    printf("步骤\t访问页面\t物理块状态(访问位,修改位)\t缺页\t置换页面\n");
    printf("----------------------------------------------------------------\n");

    for (int i = 0; i < seqLength; i++) {
        int page = sequence[i];
        int found = 0;
        int foundIndex = -1;

        // 检查页面是否已在物理块中
        for (int j = 0; j < frameCount; j++) {
            if (frames[j] == page) {
                found = 1;
                foundIndex = j;
                referenceBits[j] = 1; // 设置访问位为1
                // 50%的概率设置修改位为1（模拟页面被修改）
                if (rand() % 2 == 0) {
                    modifyBits[j] = 1;
                }
                break;
            }
        }

        if (!found) {
            result->pageFaults++;

            int emptySlot = -1;
            for (int j = 0; j < frameCount; j++) {
                if (frames[j] == -1) {
                    emptySlot = j;
                    break;
                }
            }

            if (emptySlot != -1) {
                frames[emptySlot] = page;
                referenceBits[emptySlot] = 1; // 新页面访问位设为1
                modifyBits[emptySlot] = 0;    // 初始修改位为0
                clockHand = (emptySlot + 1) % frameCount;
                printf("%2d\t%4d\t\t", i + 1, page);
                for (int j = 0; j < frameCount; j++) {
                    if (frames[j] == -1)
                        printf("     -    ");
                    else
                        printf("%2d(%d,%d) ", frames[j], referenceBits[j], modifyBits[j]);
                }
                printf("\t是\t-\n");
            } else {
                result->replacements++;

                // 改进的Clock算法：四轮扫描
                int replaced = 0;
                int startHand = clockHand;
                int replacedPage = -1;
                int replacedIndex = -1;

                // 第一轮：寻找(0,0)类页面
                for (int round = 0; round < 4 && !replaced; round++) {
                    clockHand = startHand;
                    for (int j = 0; j < frameCount && !replaced; j++) {
                        int index = (clockHand + j) % frameCount;

                        if (round == 0) {
                            // 第一轮：寻找(0,0)类页面
                            if (referenceBits[index] == 0 && modifyBits[index] == 0) {
                                replaced = 1;
                                replacedIndex = index;
                                replacedPage = frames[index];
                            }
                        } else if (round == 1) {
                            // 第二轮：寻找(0,1)类页面
                            if (referenceBits[index] == 0 && modifyBits[index] == 1) {
                                replaced = 1;
                                replacedIndex = index;
                                replacedPage = frames[index];
                            }
                        } else if (round == 2) {
                            // 第三轮：访问位置位为0
                            referenceBits[index] = 0;
                        } else if (round == 3) {
                            // 第四轮：再次寻找(0,1)类页面
                            if (referenceBits[index] == 0 && modifyBits[index] == 1) {
                                replaced = 1;
                                replacedIndex = index;
                                replacedPage = frames[index];
                            }
                        }
                    }
                }

                // 确保找到了要替换的页面
                if (replacedIndex == -1) {
                    // 如果没有找到，使用第一个页面
                    replacedIndex = 0;
                    replacedPage = frames[0];
                }

                // 替换页面
                frames[replacedIndex] = page;
                referenceBits[replacedIndex] = 1; // 新页面访问位设为1
                modifyBits[replacedIndex] = 0;    // 初始修改位为0
                clockHand = (replacedIndex + 1) % frameCount;

                printf("%2d\t%4d\t\t", i + 1, page);
                for (int j = 0; j < frameCount; j++) {
                    if (frames[j] == -1)
                        printf("     -    ");
                    else
                        printf("%2d(%d,%d) ", frames[j], referenceBits[j], modifyBits[j]);
                }
                printf("\t是\t%d\n", replacedPage);
            }
        } else {
            printf("%2d\t%4d\t\t", i + 1, page);
            for (int j = 0; j < frameCount; j++) {
                if (frames[j] == -1)
                    printf("     -    ");
                else
                    printf("%2d(%d,%d) ", frames[j], referenceBits[j], modifyBits[j]);
            }
            printf("\t否\t-\n");
        }
    }

    printf("改进Clock算法完成: 缺页次数=%d, 置换次数=%d, 缺页率=%.2f%%\n",
           result->pageFaults, result->replacements, (float)result->pageFaults / seqLength * 100);
}
```

```c
void printComparison(AlgorithmResult results[], int count) {
    printf("\n算法\t\t缺页次数\t置换次数\t缺页率\n");

    for (int i = 0; i < count; i++) {

               results[i].name,
               results[i].pageFaults,
               results[i].replacements,
               results[i].pageFaultRate);
    }

    // 找出最佳算法（缺页率最低）
    int bestIndices[10]; // 最多10个算法
    int bestCount = 0;
    float bestRate = 100.0; // 初始化为最大可能值

    for (int i = 0; i < count; i++) {
        if (results[i].pageFaultRate < bestRate) {
            bestRate = results[i].pageFaultRate;
            bestCount = 0;
            bestIndices[bestCount++] = i;
        } else if (results[i].pageFaultRate == bestRate) {
            bestIndices[bestCount++] = i;
        }

    if (bestCount == 1) {
        printf("\n最佳算法: %s (缺页率: %.2f%%)\n", results[bestIndices[0]].name, bestRate);
    } else {
        printf("\n最佳算法 (并列): ");
        for (int i = 0; i < bestCount; i++) {
            printf("%s", results[bestIndices[i]].name);
            if (i < bestCount - 1) {
                printf(", ");
            }
        }
        printf(" (缺页率: %.2f%%)\n", bestRate);
    }
}
```

## 性能指标

1. **缺页次数**：访问序列中发生缺页的总次数
2. **置换次数**：需要置换页面的次数（不包括首次加载）
3. **缺页率** = (缺页次数 / 总访问次数) × 100%
4. **最佳算法**：缺页率最低的算法

### 算法性能分析
1. **FIFO算法**：实现简单，但性能较差，存在Belady异常，适用于对性能要求不高的简单系统。
2. **OPT算法**：理论最优，缺页率最低，但需要预知未来的页面访问序列，实际中无法实现，主要用于性能比较基准。
3. **LRU算法**：性能接近OPT算法，基于局部性原理，但实现开销大，需要硬件支持，适用于高性能系统。
4. **LFU算法**：考虑历史访问模式，但可能保留不再使用的页面，实现复杂，适用于访问模式相对稳定的系统。
5. **Clock算法**：实现相对简单，性能较好，使用访问位记录页面最近是否被访问，适用于中等性能要求的系统。
6. **改进Clock算法**：考虑访问位和修改位，性能优于简单Clock算法，但实现复杂，需要维护两个标志位，适用于高性能系统。
