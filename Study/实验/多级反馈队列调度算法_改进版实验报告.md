## （3）实验内容

### 内容描述（解题思路和所使用的数据结构原理）

**解题思路**：
多级反馈队列调度算法是一种结合了时间片轮转和优先级调度的算法。本实验需要实现一个5级队列的调度系统，每级队列具有不同的时间片大小和优先级。新进程进入最高优先级队列，随着时间片用完逐渐降级，最后一级队列的进程有机会返回第一级队列，防止进程饥饿。

**数据结构原理**：
1. **进程控制块（PCB）**：记录进程的所有信息，包括名称、PID、到达时间、服务时间、剩余时间等
2. **队列结构**：使用链表实现FIFO队列，每个队列有自己的时间片大小
3. **多级队列系统**：使用数组管理5个不同优先级的队列

### 关键代码、数据结构（要有注释）

#### 3.1 关键数据结构

```c
/* ========= 进程控制块（PCB）结构 ========= */
struct PCB {
    char name[10];           // 进程名称，如"P1", "P2"
    int pid;                 // 进程PID (0~3500)
    int arriveTime;          // 到达时间 (0~100)
    int serviceTime;         // 服务时间 (20~100)
    int remainingTime;       // 剩余运行时间
    int queueLevel;          // 当前队列级别 (0-4, 0最高)
    int lastScheduledCount;  // 连续调度次数（仅用于最后一级队列）
    int startTime;           // 开始时间
    int finishTime;          // 完成时间
    PCB* next;               // 链表指针，用于队列连接
};

/* ========= 队列结构（链表实现） ========= */
struct Queue {
    PCB* head;      // 队列头指针
    PCB* tail;      // 队列尾指针
    int timeSlice;  // 时间片大小 (1~16)
    int size;       // 队列中进程数量
};
```

#### 3.2 关键函数实现

```c
/* ========= 初始化5级队列 ========= */
void initQueues() {
    bool used[17] = {false};  // 标记已使用的时间片
    for (int i = 0; i < 5; i++) {
        queues[i].head = queues[i].tail = NULL;
        queues[i].size = 0;
        int t;
        do {
            t = randBetween(1, 16);  // 生成1~16的随机数
        } while (used[t]);  // 确保时间片不重复
        used[t] = true;
        queues[i].timeSlice = t;
    }
}

/* ========= 检查新到达的进程 ========= */
void checkNewArrivals() {
    for (int i = 0; i < processCount; i++) {
        PCB* p = allProcesses[i];
        // 检查进程是否到达且未开始执行
        if (p->arriveTime == currentTime && p->startTime == -1) {
            p->queueLevel = 0;  // 加入最高优先级队列
            p->lastScheduledCount = 0;
            enqueue(0, p);  // 入队

            showProcessInfo(p, "新进程进入系统");
            showSystemState("新进程进入后队列状态");
        }
    }
}

/* ========= 调度主循环 ========= */
void schedule() {
    while (completedCount < processCount && currentTime < maxTime) {
        checkNewArrivals();  // 检查新到达进程

        // 查找最高优先级非空队列
        int selectedQueue = -1;
        for (int i = 0; i < 5; i++) {
            if (queues[i].size > 0) {
                selectedQueue = i;
                break;
            }
        }

        if (selectedQueue == -1) {
            currentTime++;  // 所有队列为空，时间推进
            continue;
        }

        // 从队列中取出进程执行
        PCB* p = dequeue(selectedQueue);
        if (p->startTime == -1) {
            p->startTime = currentTime;  // 记录开始时间
        }

        int slice = queues[selectedQueue].timeSlice;
        int runTime = (p->remainingTime < slice) ? p->remainingTime : slice;

        // 模拟时间流逝
        for (int t = 0; t < runTime; t++) {
            currentTime++;
            p->remainingTime--;
            checkNewArrivals();  // 检查在此期间到达的新进程
        }

        if (p->remainingTime == 0) {
            // 进程完成
            p->finishTime = currentTime;
            completedCount++;
            showProcessInfo(p, "进程离开系统");
            showSystemState("进程离开后队列状态");
        } else {
            // 进程未完成，根据规则重新加入队列
            if (selectedQueue == 4) {
                // 最后一级队列特殊规则
                p->lastScheduledCount++;
                if (p->lastScheduledCount >= 2) {
                    // 连续调度两次未完成，返回第一级队列
                    p->lastScheduledCount = 0;
                    enqueue(0, p);
                } else {
                    enqueue(4, p);  // 留在最后一级队列
                }
            } else {
                enqueue(selectedQueue + 1, p);  // 降级到下一级队列
            }
            showSystemState("进程重新加入后队列状态");
        }
    }
}
```

### 遇到的问题及解决方式
1. **问题**：进程到达时间处理不准确，导致进程提前或延迟进入系统。
   - **解决**：在`checkNewArrivals()`函数中精确检查当前时间是否等于进程到达时间，并且确保进程未开始执行。

2. **问题**：最后一级队列的特殊规则触发条件不正确。
   - **解决**：在PCB结构中添加`lastScheduledCount`字段，专门用于记录在最后一级队列中的连续调度次数，当次数达到2时触发返回第一级队列的规则。

3. **问题**：系统状态显示混乱，信息不清晰。
   - **解决**：设计统一的显示函数`showSystemState()`和`showProcessInfo()`，使用格式化输出和分隔线，使信息层次清晰。

4. **问题**：内存泄漏问题。
   - **解决**：在主函数结束时，遍历所有进程指针数组，使用`delete`释放动态分配的内存。

5. **问题**：调度过程中可能出现无限循环。
   - **解决**：在调度主循环中添加最大时间限制（如1000单位时间），防止因逻辑错误导致的无限循环。
