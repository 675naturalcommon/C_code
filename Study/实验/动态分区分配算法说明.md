## 动态分区分配原理

### 基本概念
动态分区分配是一种可变分区存储管理方式，在系统运行过程中根据进程的实际需求动态地划分内存空间。

### 工作原理
1. **初始化**: 系统启动时，整个用户区作为一个大的空闲分区
2. **分配过程**: 当进程申请内存时，系统在空闲分区中寻找合适的分区
3. **分区分割**: 如果找到的分区大于需求，将分区分割为两部分
   - 已分配部分：分配给进程
   - 剩余部分：作为新的空闲分区
4. **回收过程**: 进程结束时，回收其占用的分区，并合并相邻的空闲分区

### 关键特点
- **动态性**: 分区大小和数量在运行过程中动态变化
- **灵活性**: 适应不同大小的进程需求
- **碎片问题**: 会产生外部碎片，需要通过紧凑技术解决

### 内存碎片问题
1. **外部碎片**: 分布在已分配分区之间的空闲分区太小，无法满足进程需求
2. **内部碎片**: 分配给进程的分区大于实际需求，造成空间浪费
3. **解决方案**:
   - 紧凑技术：移动已分配分区，合并空闲分区
   - 分区大小限制：设置最小分区大小
   - 动态重定位：支持进程在内存中移动

### 1. 关键数据结构与代码实现

#### 分区结构体 (Partition) - 核心数据结构
```cpp
struct Partition {
    int start;      // 分区起始地址 - 内存中的起始位置
    int size;       // 分区大小 - 以KB为单位
    bool free;      // 是否空闲 - true表示空闲，false表示已分配
    string process; // 占用进程名 - 如果被占用，记录进程名称

    // 构造函数 - 初始化分区信息
    Partition(int s, int sz, bool f = true, string p = "")
        : start(s), size(sz), free(f), process(p) {}
};
```

#### 分区分割代码实现
```cpp
// 分配分区（内部方法）
void allocatePartition(int index, int size, const string& processName) {
    Partition& part = partitions[index];

    if (part.size == size) {
        // 分区大小正好等于请求大小 - 直接分配
        part.free = false;
        part.process = processName;
    } else {
        // 分区大小大于请求大小 - 需要分割
        // 创建新的空闲分区（剩余部分）
        Partition newPart(part.start + size, part.size - size, true, "");

        // 修改当前分区为已分配状态
        part.size = size;
        part.free = false;
        part.process = processName;

        // 在分区表中插入新的空闲分区
        partitions.insert(partitions.begin() + index + 1, newPart);
    }

    cout << "成功分配 " << size << "KB 给进程 " << processName
         << "，起始地址：" << part.start << endl;
}
```

#### 分区合并代码实现
```cpp
// 合并相邻的空闲分区（内部方法）
void mergeFreePartitions() {
    for (int i = 0; i < partitions.size() - 1; i++) {
        if (partitions[i].free && partitions[i+1].free) {
            // 合并相邻的空闲分区
            partitions[i].size += partitions[i+1].size;

            // 删除被合并的分区
            partitions.erase(partitions.begin() + i + 1);

            i--;  // 重新检查当前位置，因为删除了一个元素
        }
    }
}
```

### 2. 分配算法核心原理与代码实现

#### 搜索策略对比
| 算法类型 | 搜索起点 | 搜索方向 | 选择标准 | 优缺点 |
|---------|---------|---------|---------|--------|
| 首次适应 | 低地址 | 顺序 | 第一个足够大 | 简单快速，低地址碎片 |
| 循环首次 | 上次位置 | 循环 | 第一个足够大 | 分配均匀，减少低地址碎片 |
| 最佳适应 | 低地址 | 顺序 | 最小足够大 | 空间利用率高，小碎片多 |
| 最坏适应 | 低地址 | 顺序 | 最大空闲区 | 减少小碎片，可能浪费大空间 |

#### 算法时间复杂度
- **首次适应**: O(n) - 最坏情况需要遍历整个分区表
- **循环首次**: O(n) - 平均性能优于首次适应
- **最佳适应**: O(n) - 需要遍历所有空闲分区
- **最坏适应**: O(n) - 需要遍历所有空闲分区

#### 首次适应算法代码实现
```cpp
bool firstFit(int size, const string& processName) {
    cout << "使用首次适应算法分配 " << size << "KB 给进程 " << processName << endl;

    for (int i = 0; i < partitions.size(); i++) {
        if (partitions[i].free && partitions[i].size >= size) {
            allocatePartition(i, size, processName);
            return true;
        }
    }

    cout << "分配失败：没有足够的连续空间" << endl;
    return false;
}
```

#### 循环首次适应算法代码实现
```cpp
bool nextFit(int size, const string& processName) {
    cout << "使用循环首次适应算法分配 " << size << "KB 给进程 " << processName << endl;

    int startIndex = lastAllocatedIndex;
    int currentIndex = startIndex;

    do {
        if (partitions[currentIndex].free && partitions[currentIndex].size >= size) {
            allocatePartition(currentIndex, size, processName);
            lastAllocatedIndex = currentIndex;
            return true;
        }

        currentIndex = (currentIndex + 1) % partitions.size();
    } while (currentIndex != startIndex);

    cout << "分配失败：没有足够的连续空间" << endl;
    return false;
}
```

#### 最佳适应算法代码实现
```cpp
bool bestFit(int size, const string& processName) {
    cout << "使用最佳适应算法分配 " << size << "KB 给进程 " << processName << endl;

    int bestIndex = -1;
    int minSize = totalMemory + 1;  // 初始化为一个很大的值

    for (int i = 0; i < partitions.size(); i++) {
        if (partitions[i].free && partitions[i].size >= size) {
            if (partitions[i].size < minSize) {
                minSize = partitions[i].size;
                bestIndex = i;
            }
        }
    }

    if (bestIndex != -1) {
        allocatePartition(bestIndex, size, processName);
        return true;
    }

    cout << "分配失败：没有足够的连续空间" << endl;
    return false;
}
```

#### 最坏适应算法代码实现
```cpp
bool worstFit(int size, const string& processName) {
    cout << "使用最坏适应算法分配 " << size << "KB 给进程 " << processName << endl;

    int worstIndex = -1;
    int maxSize = -1;

    for (int i = 0; i < partitions.size(); i++) {
        if (partitions[i].free && partitions[i].size >= size) {
            if (partitions[i].size > maxSize) {
                maxSize = partitions[i].size;
                worstIndex = i;
            }
        }
    }

    if (worstIndex != -1) {
        allocatePartition(worstIndex, size, processName);
        return true;
    }

    cout << "分配失败：没有足够的连续空间" << endl;
    return false;
}
```

### 2. 分配算法（4种）

#### 首次适应算法 (First Fit)
- 从内存低地址开始搜索第一个足够大的空闲分区
- 特点：简单快速，但容易在低地址产生碎片

#### 循环首次适应算法 (Next Fit)
- 从上次分配的位置开始循环搜索
- 特点：分配更均匀，减少低地址碎片

#### 最佳适应算法 (Best Fit)
- 搜索能够满足需求的最小空闲分区
- 特点：减少空间浪费，但容易产生小碎片

#### 最坏适应算法 (Worst Fit)
- 搜索最大的空闲分区进行分配
- 特点：减少小碎片产生，但可能浪费大块空间

### 3. 回收算法原理

#### 回收情况分类
1. **情况1**: 回收区与插入点的前一个空闲分区相邻
   - 操作：与前一个空闲分区合并
   - 结果：分区表大小不变，前一个分区大小增加

2. **情况2**: 回收区与插入点的后一个空闲分区相邻
   - 操作：与后一个空闲分区合并
   - 结果：分区表大小不变，后一个分区起始地址前移，大小增加

3. **情况3**: 回收区同时与插入点的前、后两个分区相邻
   - 操作：与前后两个空闲分区合并
   - 结果：分区表大小减1，前一个分区大小增加（包含回收区和后一个分区）

4. **情况4**: 回收区不与前后空闲分区相邻
   - 操作：创建新的空闲分区
   - 结果：分区表大小加1

#### 回收算法实现
- **搜索定位**: 根据进程名在分区表中定位要回收的分区
- **状态更新**: 将分区标记为空闲状态
- **相邻检查**: 检查前后相邻分区是否空闲
- **分区合并**: 根据相邻情况执行相应的合并操作
- **表维护**: 更新分区表，保持地址顺序

## 技术要点

### 1. 分区分割策略
- **精确匹配**: 当请求大小等于分区大小时，直接分配整个分区
- **分割分配**: 当请求大小小于分区大小时，分割为已分配区和剩余空闲区
- **地址连续性**: 保持分区地址的连续性，新分区的起始地址 = 原分区起始地址 + 分配大小

### 2. 分区合并机制
- **相邻检测**: 检查回收区前后相邻分区的空闲状态
- **合并条件**: 仅当相邻分区都空闲时才进行合并
- **表维护**: 合并后删除多余的分区条目，保持表结构紧凑

### 3. 循环搜索实现
- **环形遍历**: 使用取模运算实现环形搜索 `currentIndex = (currentIndex + 1) % partitions.size()`
- **终止条件**: 当搜索回到起始位置时终止
- **状态维护**: 记录上次分配位置，实现循环特性

### 4. 最优选择策略
- **最佳适应**: 遍历所有空闲分区，选择大小最接近请求的分区
- **最坏适应**: 遍历所有空闲分区，选择最大的空闲分区
- **比较机制**: 通过维护最小/最大值变量实现最优选择

### 5. 数据结构操作
- **动态调整**: 使用 `vector` 的 `insert()` 和 `erase()` 方法动态调整分区表
- **状态同步**: 实时更新分区的空闲状态和进程占用信息
- **边界处理**: 正确处理内存边界和分区大小限制
