# 高响应比优先调度算法 (HRRN) 说明文档

## 目的
高响应比优先调度算法的目的是在非抢占式调度环境中，平衡短作业优先和长作业公平性的需求。通过动态计算响应比，既能让短作业得到优先执行，又能避免长作业因长时间等待而饥饿。

## 算法原理

高响应比优先调度算法是一种非抢占式调度算法，它结合了FCFS和SJF算法的优点。该算法的核心思想是通过动态计算每个进程的响应比来决定下一个执行的进程。

### 响应比计算公式
**响应比 = (等待时间 + 服务时间) / 服务时间**

其中：
- **等待时间** = 当前时间 - 进程到达时间
- **服务时间** = 进程需要的执行时间

### 算法执行流程
1. **初始化**：将所有进程按到达时间排序
2. **选择进程**：在当前时间下，计算所有已到达且未执行进程的响应比
3. **执行进程**：选择响应比最高的进程执行
4. **更新状态**：执行完成后更新系统时间，标记该进程为已完成
5. **重复执行**：重复步骤2-4，直到所有进程执行完成

### 算法特点
- **动态优先级**：响应比会随着等待时间的增加而提高
- **避免饥饿**：长作业的等待时间越长，响应比越高，最终会被执行
- **兼顾效率**：短作业的服务时间小，响应比相对较高
- **非抢占式**：进程一旦开始执行，就会运行到完成

## 算法特点

1. **非抢占式**：一旦进程开始执行，就会一直执行到完成
2. **动态优先级**：响应比会随着等待时间的增加而提高
3. **兼顾公平性**：既考虑了短作业优先，又避免了长作业饥饿
4. **计算复杂度**：每次选择进程时需要计算所有已到达进程的响应比

## 关键数据结构
### 进程结构体 (Process)
```c
typedef struct {
    int id;                    // 进程ID
    int arriveTime;           // 到达时间
    int serviceTime;          // 服务时间
    int startTime;            // 开始时间
    int finishTime;           // 完成时间
    int turnaroundTime;       // 周转时间
    float weightedTurnaroundTime; // 带权周转时间
    int waitingTime;          // 等待时间
    float responseRatio;      // 响应比
} Process;
```

### 主要变量
- `Process processes[MAX_PROCESS]` - 进程数组，最大容量10个进程
- `int currentTime` - 当前系统时间
- `int completed` - 已完成的进程数
- `int visited[MAX_PROCESS]` - 标记数组，记录进程是否已执行

#### 处理函数
**HRRN算法主函数**
```c
void HRRN(Process processes[], int n) {
    Process temp[MAX_PROCESS];
    memcpy(temp, processes, sizeof(Process) * n);
    sortByArriveTime(temp, n);

    int currentTime = 0, completed = 0;
    int visited[MAX_PROCESS] = {0};

    while (completed < n) {
        int selectedIndex = -1;
        float maxResponseRatio = -1.0;

        // 计算所有已到达进程的响应比
        for (int i = 0; i < n; i++) {
            if (!visited[i] && temp[i].arriveTime <= currentTime) {
                int waitingTime = currentTime - temp[i].arriveTime;
                temp[i].responseRatio = (float)(waitingTime + temp[i].serviceTime) / temp[i].serviceTime;

                if (temp[i].responseRatio > maxResponseRatio) {
                    maxResponseRatio = temp[i].responseRatio;
                    selectedIndex = i;
                }
            }
        }

        // 执行选中的进程
        if (selectedIndex != -1) {
            temp[selectedIndex].startTime = currentTime;
            temp[selectedIndex].finishTime = currentTime + temp[selectedIndex].serviceTime;
            temp[selectedIndex].turnaroundTime = temp[selectedIndex].finishTime - temp[selectedIndex].arriveTime;
            temp[selectedIndex].weightedTurnaroundTime = (float)temp[selectedIndex].turnaroundTime / temp[selectedIndex].serviceTime;
            temp[selectedIndex].waitingTime = temp[selectedIndex].startTime - temp[selectedIndex].arriveTime;

            currentTime = temp[selectedIndex].finishTime;
            visited[selectedIndex] = 1;
            completed++;
        } else {
            // 推进时间到下一个进程到达时间
            int nextArrival = 1000;
            for (int i = 0; i < n; i++) {
                if (!visited[i] && temp[i].arriveTime < nextArrival) {
                    nextArrival = temp[i].arriveTime;
                }
            }
            currentTime = nextArrival;
        }
    }
}
```

**按到达时间排序**
```c
void sortByArriveTime(Process processes[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (processes[j].arriveTime > processes[j + 1].arriveTime) {
                Process temp = processes[j];
                processes[j] = processes[j + 1];
                processes[j + 1] = temp;
            }
        }
    }
}
```

**打印甘特图**
```c
void printGanttChart(Process processes[], int n) {
    int maxTime = 0;
    for (int i = 0; i < n; i++) {
        if (processes[i].finishTime > maxTime) maxTime = processes[i].finishTime;
    }

    printf("时间轴: ");
    for (int i = 0; i <= maxTime; i++) printf("%2d ", i);
    printf("\n");

    for (int i = 0; i < n; i++) {
        printf("P%d:    ", processes[i].id);
        for (int t = 0; t <= maxTime; t++) {
            if (t >= processes[i].startTime && t < processes[i].finishTime) {
                printf("██ ");
            } else {
                printf("   ");
            }
        }
        printf("\n");
    }
}
```

## 性能指标

1. **周转时间** = 完成时间 - 到达时间
2. **带权周转时间** = 周转时间 / 服务时间
3. **平均周转时间**：所有进程周转时间的平均值
4. **平均带权周转时间**：所有进程带权周转时间的平均值
5. **处理机利用率** = (总服务时间 / 总执行时间) × 100%
