# 学生成绩管理系统

一个使用C语言开发的完整学生成绩管理系统，具有添加、删除、修改、查询、统计等功能。

## 功能特性

- ✅ **学生信息管理**：添加、删除、修改学生基本信息
- ✅ **动态科目管理**：每个学生可以有不同的科目，支持自定义科目名称
- ✅ **成绩管理**：添加、删除、修改各科成绩
- ✅ **自动计算**：自动计算总分和平均分
- ✅ **查询功能**：按学号或姓名查询学生信息
- ✅ **成绩统计**：统计各科平均分、最高分、最低分
- ✅ **排名功能**：按总分自动排序并显示前三名
- ✅ **数据持久化**：自动保存和加载数据到文件
- ✅ **输入验证**：完善的输入验证和错误处理

## 系统要求

- Windows 操作系统
- GCC 编译器（已包含在系统中）

## 使用方法

1. **运行程序**：
   ```bash
   cd "项目/学生成绩管理系统"
   .\student_management_system.exe
   ```

2. **系统菜单**：
   ```
   ========== 菜单 ==========
   1. 添加学生信息
   2. 删除学生信息
   3. 修改学生信息
   4. 查询学生信息
   5. 显示所有学生
   6. 统计信息
   7. 保存数据
   8. 退出系统

   ```

## 功能说明

### 1. 添加学生信息
- 输入学号、姓名
- 自动检查学号是否重复
- 可选择添加任意科目的成绩
- 支持自定义科目名称
- 自动计算总分和平均分
- 成绩范围限制在0-100分

### 2. 删除学生信息
- 按学号删除学生
- 删除前显示确认信息
- 防止误删除

### 3. 修改学生信息
- 按学号修改学生信息
- 支持修改姓名
- 支持添加、修改、删除各科成绩
- 修改后自动重新计算总分和平均分

### 4. 查询学生信息
- 按学号精确查询
- 按姓名模糊查询
- 显示完整的学生信息

### 5. 显示所有学生
- 按总分降序排列
- 显示所有学生的详细信息
- 表格化显示，便于查看

### 6. 统计信息
- 自动识别所有科目并分别统计
- 统计各科平均分、最高分、最低分
- 显示参考人数
- 显示总分前三名学生
- 提供全面的成绩分析

### 7. 保存数据
- 手动保存数据到文件
- 退出系统时自动保存

### 8. 退出系统
- 安全退出并自动保存数据

## 数据结构

系统使用结构体存储学生信息，支持动态科目管理：
```c
// 成绩结构体
typedef struct {
    char subject[MAX_SUBJECT_NAME_LENGTH];  // 科目名称
    float score;                            // 成绩
} Grade;

// 学生结构体
typedef struct {
    char id[MAX_ID_LENGTH];                // 学号
    char name[MAX_NAME_LENGTH];            // 姓名
    Grade grades[MAX_SUBJECTS];            // 成绩数组
    int grade_count;                       // 成绩数量
    float total;                           // 总分
    float average;                         // 平均分
} Student;
```

## 技术特点

- **模块化设计**：功能模块清晰分离
- **错误处理**：完善的输入验证和错误提示
- **数据持久化**：使用文件系统保存数据
- **用户友好**：中文界面，操作简单
- **性能优化**：使用冒泡排序算法进行成绩排序

## 注意事项

1. 系统最多支持100名学生
2. 学号长度不超过20个字符
3. 姓名长度不超过50个字符
4. 每个学生最多支持10个科目
5. 科目名称长度不超过30个字符
6. 成绩范围为0-100分
7. 数据文件会自动保存在程序同目录下
