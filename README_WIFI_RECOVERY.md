# WiFi密码恢复工具

## 简介
这是一个Python程序，用于帮助用户找回自己路由器的WiFi密码。程序提供了三种方法来恢复WiFi密码：

1. **从Windows系统读取已保存的密码** - 读取Windows系统中已保存的WiFi配置文件密码
2. **通过路由器管理界面获取** - 获取路由器IP地址并提供常见登录凭据
3. **增强版密码破解（仅用于教育目的）** - 使用智能密码生成算法进行暴力破解模拟

## 使用前提
- Windows操作系统
- Python 3.x
- 管理员权限（某些功能可能需要）

## 安装与运行

### 1. 直接运行
```bash
python wifi_password_recovery.py
```

### 2. 使用特定方法
```bash
# 只读取已保存的密码
python wifi_password_recovery.py --method saved

# 只获取路由器信息
python wifi_password_recovery.py --method router

# 只进行密码破解（模拟）
python wifi_password_recovery.py --method bruteforce --ssid "WiFi名称" --max-attempts 1000

# 使用自定义密码字典文件
python wifi_password_recovery.py --method bruteforce --ssid "WiFi名称" --wordlist-file "密码字典.txt"

# 生成密码字典文件
python wifi_password_recovery.py --generate-wordlist --ssid "WiFi名称" --wordlist-size 500
```

### 3. 查看帮助
```bash
python wifi_password_recovery.py --help
```

## 功能详解

### 方法1：从Windows系统读取已保存的密码
- 使用Windows的`netsh wlan`命令读取所有已保存的WiFi配置文件
- 提取每个配置文件的密码
- 显示所有找到的WiFi名称和对应密码

### 方法2：通过路由器管理界面获取
- 使用`ipconfig`命令获取默认网关（通常是路由器IP）
- 提供路由器管理界面的访问地址
- 列出常见的路由器登录凭据（用户名/密码组合）

### 方法3：增强版密码破解（仅用于教育目的）
- **智能密码生成**：基于SSID名称、路由器品牌、常见密码模式生成密码字典
- **多种密码模式**：
  - 常见密码（12345678, password, admin123等）
  - 数字序列密码（00000000-99999999）
  - 键盘模式密码（qwertyui, asdfghjk等）
  - 日期格式密码（YYYYMMDD, DDMMYYYY等）
  - 电话号码模式（中国手机号格式）
  - 组合密码（基础密码+后缀/前缀）
- **在线密码字典**：
  - 从GitHub等开源项目下载密码字典
  - 集成多个公开密码字典资源
  - 自动合并和去重
  - 在本地字典穷尽后提供在线字典选项
- **进度显示**：实时显示破解进度和统计信息
- **结果保存**：自动保存找到的密码到文件
- **密码字典管理**：
  - 支持从文件加载自定义密码字典
  - 支持生成并保存密码字典到文件
  - 支持智能密码生成（基于SSID分析）
  - 支持在线字典下载和合并

## 常见问题

### Q1: 程序无法运行，提示编码错误
A: 程序已使用UTF-8编码并忽略错误，如果仍有问题，请确保系统语言设置正确。

### Q2: 找不到已保存的WiFi密码
A: 请确保：
1. 当前用户有权限访问WiFi配置文件
2. 计算机曾经连接过该WiFi
3. 运行程序时使用管理员权限

### Q3: 路由器管理界面无法登录
A: 尝试以下方法：
1. 查看路由器底部的标签，通常有默认用户名和密码
2. 尝试常见的用户名/密码组合（admin/admin, admin/password等）
3. 重置路由器到出厂设置（注意：这会丢失所有配置）

### Q4: 程序显示的密码不正确
A: 程序直接从Windows系统读取密码，如果密码不正确可能是：
1. WiFi密码已更改但Windows中保存的是旧密码
2. 需要重新连接WiFi以更新保存的密码
