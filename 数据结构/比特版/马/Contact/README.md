# 通讯录管理系统（顺序表实现）

一个基于C语言和顺序表数据结构实现的通讯录管理系统，支持联系人信息的增删改查、排序等功能。参考了Sequence目录下的顺序表实现方式。

## 文件结构

```
Contact/
├── Contact.h      # 头文件，包含数据结构和函数声明
├── Contact.c      # 源文件，包含函数实现
├── test.c         # 测试文件，包含主程序和菜单界面
├── manual_test.c  # 手动测试程序
├── contact_system.exe  # 编译后的可执行文件
├── manual_test.exe     # 手动测试可执行文件
└── README.md      # 说明文档
```

## 功能特性

### 1. 联系人数据结构

- 姓名（最大20字符）
- 性别（最大10字符）
- 年龄（整数）
- 电话（最大20字符）
- 地址（最大100字符）

### 2. 核心功能

- **添加联系人**：添加新的联系人信息
- **显示所有联系人**：以表格形式显示所有联系人
- **删除联系人**：根据姓名删除联系人
- **查找联系人**：根据姓名查找联系人
- **修改联系人**：根据姓名修改联系人信息
- **清空通讯录**：清空所有联系人
- **按姓名排序**：按姓名升序排序联系人
- **退出系统**：安全退出并释放内存

### 3. 内存管理

- 动态内存分配，初始容量为3个联系人
- 自动扩容机制，当容量不足时自动增加2个位置
- 程序退出时自动释放所有内存

## 技术实现

### 数据结构

```c
// 联系人信息结构
typedef struct personInfo
{
    char name[NAME_MAX];
    char gender[GENDER_MAX];
    int age;
    char tel[TEL_MAX];
    char addr[ADDR_MAX];
} peoInfo;

// 通讯录结构
typedef struct Contact
{
    peoInfo *data; // 指向存放联系人数据的数组
    int size;      // 当前通讯录中有效联系人的个数
    int capacity;  // 当前通讯录的最大容量
} Contact;
```

### 主要函数（基于顺序表实现）

- `ContactInit()`: 初始化通讯录
- `ContactAdd()`: 添加联系人（尾插）
- `ContactShow()`: 显示所有联系人
- `ContactDelete()`: 删除联系人（按姓名）
- `ContactSearch()`: 查找联系人（按姓名）
- `ContactModify()`: 修改联系人信息（按姓名）
- `ContactClear()`: 清空通讯录
- `ContactDestroy()`: 销毁通讯录
- `ContactSort()`: 按姓名排序
- `ContactFindByName()`: 按姓名查找联系人（返回位置）
- `ContactCheckCapacity()`: 检查容量并扩容

## 注意事项

1. 姓名是联系人的唯一标识，用于查找、修改和删除操作
2. 系统使用动态内存管理，确保正确处理内存分配和释放
3. 输入数据时请确保符合字段长度限制
4. 程序退出时会自动释放所有分配的内存
